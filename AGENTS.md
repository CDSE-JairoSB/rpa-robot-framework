# Agent Instructions

## Agent skills

### Issue tracker

Issues and specifications are tracked in GitHub Issues for `CDSE-JairoSB/rpa-robot-framework`; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context layout with a root `GLOSSARY.md` and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
