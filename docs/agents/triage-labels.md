# Triage Labels

The engineering skills use five canonical triage roles. This file maps those roles to the label strings used in this repository's GitHub issue tracker.

| Label in mattpocock/skills | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | More information is required before work can proceed |
| `ready-for-agent` | `ready-for-agent` | An agent can implement the requested work |
| `ready-for-human` | `ready-for-human` | Human review or decision is required |
| `wontfix` | `wontfix` | The issue will not be addressed |

These mappings are intentionally identical to the canonical names. The triage workflow should use the existing labels when available and avoid creating duplicate labels with different names.
